# Namma-Kathey (National Pride)

### Android-Based Interactive Storytelling Application

An educational Android application designed to introduce children and students to the inspiring heroes, freedom fighters, poets, and social reformers of Karnataka through interactive storytelling and quizzes.

</div>

---

# 📌 Project Overview

**Namma-Kathey** is an Android-based interactive storytelling application developed to promote Karnataka’s culture, history, and moral values among children and students.

The application provides:

- 📖 District-wise inspirational stories
- 🗺️ Interactive exploration of Karnataka districts
- ❓ Quiz-based learning activities
- 🎨 Child-friendly user interface
- 📱 Smooth Android mobile experience

This project was developed as part of the internship titled:

> **Android App Development using Gen AI**
